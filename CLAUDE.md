# Shellie

A desktop app for running development tasks as isolated workspaces, with AI cost tracking per task. The app was called MIAC ("Me, I'm Counting", after a Culture ship) until 2026-10-18.

## What it does

- **Task = worktree + branch + terminals**, tied to an Azure DevOps work item.
  - Create a git worktree and branch from a work item.
  - Run per-repo setup (e.g. `npm ci`) after creating the worktree.
  - Open the task's terminals: Claude Code, GitHub Copilot, PowerShell, dev server.
  - Clean up the worktree and branch when the task is done.
- **AI cost tracking per task.**
  - Track Claude Code and Copilot token usage per task, using OpenTelemetry tagged with the task id.
  - Price usage with our own rate table, in EUR.
  - Log the cost on the work item via custom fields plus a comment.
  - Why: we use consumption-based licences and invoice customers for AI cost.

## Tech

- Electron + xterm.js + node-pty.
- Electron Forge (Vite + React + TypeScript), Vitest.
- **Windows is the release target**, but development happens on macOS first (decided 2026-10-14). All shell, path and spawn logic goes behind the `Platform` interface so the Windows implementation is a module swap, not a rewrite.

## Conventions

- Per-repo setup file: `.shellie.yml` (setup commands, terminals, dev server, etc.).
- CLI entry point: `shellie start <workitem>`.

- Secrets (spec `docs/superpowers/specs/2026-10-23-secrets-design.md`, mockups `design/mockups/secrets/`) implemented 2026-10-23 on `feature/secrets`: Settings › Secrets is a per-scope manager (one repo or All repositories; a repo's own secret wins over an All one of the same name) with a column per environment (Development, Test, UAT, Production), masked values with hold-to-reveal (reveals logged locally), where each is given and a green/amber status panel (amber while a `copy:` file still holds a stored value, a stored value is committed in a tracked file, an open worktree still has an old plaintext copy, or git could not be checked). Values live in `<userData>/secrets.json`, encrypted with safeStorage and decrypted in main only (`src/main/secrets/SecretStore.ts`). Discovery (`discover.ts`, `sources/`) reads the repo's main checkout (root and two folders down: `.env*`, `appsettings.<Env>.json`, `Properties/launchSettings.json`, `.vscode/launch.json`, docker-compose, `local.settings.json`, `secrets/`, `*.secrets.json`) plus .NET user secrets (`Platform.userSecretsDir`), only when the import page opens; Import (`importPlan.ts`) has a row per key and a column per environment with conflicts, gaps, an Unassigned lane, and options to rewrite open worktrees' copies (default on) and take the keys out of the main checkout's `.env`-style files (default off; never JSON, user secrets or tracked files). Injection (`inject.ts`, `spawnTerminal`): Setup, run/dev-server, test and (opt-in per secret) shell tabs get the task environment's values, plus `ASPNETCORE_ENVIRONMENT`/`DOTNET_ENVIRONMENT` (and `NODE_ENV` for run and shell tabs) and a matching `--launch-profile` for `dotnet run`, only when the repo has a stored secret; agent tabs never do; `copy:` writes env files without stored keys. Each task has an environment (New task picks it, Start uses the repo default, never UAT/Production); the task bar chip switches it and restarts only the tabs that hold secrets (the Setup tab is only stopped); UAT and Production need a confirm and show a band (amber/red), Production ends after `secrets.productionMinutes` (default 60, min 5; `expiry.ts`, checked every 30 s and on resume) and at Finish; the environment shows in the breadcrumb, tab labels, the Done page and the draft PR description. Leak watch (`LeakMatcher.ts`, `LeakWatch.ts`, `leakScan.ts`) masks every environment's stored values (and base64 forms, 8+ chars) in agent output as `[NAME]` with a notice, pauses the tab's input for a Production value (Resume / Stop), flags Changes rows, and Finish refuses a push whose commits add one (or that it could not check) until confirmed; values from tracked files are masked without a notice. `shellie run <name> [-- args]` (`RunHub.ts`, `shim.ts`, shims in `<userData>/bin`, `SHELLIE_RUN_URL` + per-task token) runs only named commands (`run:` entries, `test`, `setup`) in a visible `agent · <name>` tab with the secrets and returns leak-filtered output and the exit code; UAT and Production runs wait for an approve bar that shows the resolved script (package.json pre/post scripts, bidi controls marked); Claude's system prompt and OpenCode's instructions name the commands. Claude Code `--settings` and OpenCode's permission config deny reading the untracked secret files discovery found (`deny.ts`); Copilot has no equivalent. Clean worktrees (Secrets page, task bar) rewrites old copies and restarts the secret tabs. Telemetry `secrets.*` (counts, source kinds, the four environment names, booleans) in `docs/telemetry.md`. Verified live on macOS on 2026-10-23 on a fresh profile against a scratch repo (`.superpowers/sdd/2026-10-23-secrets/task-11-report.md`; the Claude Code tab was a stand-in shell with the agent environment, no model). Known gaps: `shellie run` and leak watch guard against accidental exposure, not a hostile agent (an agent can edit what a named command runs; UAT/Production approvals show the resolved script); leak watch detects, it does not prevent (the model has seen a value before it is masked); right after a secret is saved, values from tracked files count as loud until the tracked-file list loads again, so the first one shown can pause a tab; the notice and Production pause of a `shellie run` go to the agent tab that asked although the agent only got the masked output; values split by more than 50 ms or by escape codes and multi-line values (PEM) are not matched in terminals; no "N secrets found" notice when a repo is added (discovery runs only on the import page); framework environment spelling is not overridable per repo; Windows shims, cmd argument refusal, deny paths (Claude `//c/` form) and user-secrets paths verified by CI only; OpenCode's absolute-path deny for files outside the worktree and its `secrets/**` pattern unverified live.
